BEFORE PUBLISHING
1. Replace novaoptimization30@gmail.com in terms.html and privacy.html with an email address you monitor.
2. Audit the bot code, database, logs, hosting provider, enabled Discord intents, and external APIs.
3. Edit the Privacy Policy so it accurately states what NOVA actually collects, stores, shares, and deletes.
4. Confirm the Terms match NOVA's actual features and intended use.
5. This is a template, not legal advice or a guarantee of Discord verification/legal compliance.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a PUBLIC repository, e.g. nova-legal-pages.
3. Upload index.html, terms.html, and privacy.html to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for publishing. GitHub will show the public site URL in Settings -> Pages.
7. Your URLs will look like:
   https://YOUR-GITHUB-USERNAME.github.io/nova-legal-pages/
   https://YOUR-GITHUB-USERNAME.github.io/nova-legal-pages/terms.html
   https://YOUR-GITHUB-USERNAME.github.io/nova-legal-pages/privacy.html
   Replace YOUR-GITHUB-USERNAME with your actual username.
8. In Discord Developer Portal -> NOVA -> General Information, set Terms of Service URL and Privacy Policy URL to the corresponding live links.

NOTE: GitHub Pages is free for public repositories on GitHub Free. GitHub Pages logs visitor IP addresses for security purposes; see GitHub's privacy documentation.
